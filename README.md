# filetype-cleaner

一个面向大量小文件的 Go 命令行工具，可以按扩展名安全删除文件，也可以把子目录文件展平到扫描根目录。默认处于预览模式，只有明确指定 `--delete` 或 `--apply` 才会修改文件。

## 快速使用

先预览 `.c` 和 `.h` 文件：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h"
```

确认列表和统计无误后执行删除：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --delete
```

程序会要求输入大写的 `DELETE`。脚本或自动化任务可以跳过交互确认：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --delete --yes --log "delete.log"
```

扩展名不区分大小写；`.c`、`c` 和 `*.c` 都可以。多段扩展名也受支持，例如 `.tar.gz`。使用 `--no-ext` 选择没有扩展名的文件：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --no-ext
```

也可以同时选择指定扩展名和无扩展名文件：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --no-ext
```

旧写法 `--ext none` 仍然支持。

使用 `--exclude` 排除相对路径或文件名中包含指定关键词的项目，匹配不区分大小写：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --exclude "vendor,temp,artifacts"
```

多个关键词使用逗号分隔。命中文件时跳过该文件；命中目录时跳过整个目录树。关键词只检查 `--root` 以下的相对路径，不会因根目录本身含有关键词而排除全部内容。

使用 `--exclude-content` 保留内容中含有指定关键词的文件，匹配不区分大小写：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --exclude-content "generated by,do not delete"
```

内容检查只针对原本会进入处理列表的普通文件，不跟随符号链接。默认单个文件最多检查 16 MiB；超过上限的文件会安全保留并显示在摘要中。可调整上限，`0` 表示不限制：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".txt" --exclude-content "keep" --content-max-mib 64
```

## 反向模式

增加 `--invert` 后，指定类型会被保留，其他类型进入预览或删除列表：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --invert
```

如果无扩展名文件也需要保留，同时指定 `--no-ext`：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --no-ext --invert
```

反向模式仍然默认只预览。确认列表无误后才能增加 `--delete`；`--exclude` 命中的路径始终保留。

## 保留预览

工具默认显示前 20 个明确保留的路径，并标明保留原因。使用 `--keep-preview` 调整数量，`0` 表示不显示：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --invert --preview 30 --keep-preview 30
```

待处理文件由 `--preview` 控制，保留文件由 `--keep-preview` 独立控制。路径关键词命中的目录只显示目录本身，因为其子树不会继续扫描。

## 空文件夹

使用 `--empty-dirs` 选择空文件夹，可以独立使用：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --empty-dirs
```

也可以和文件类型规则组合。预览会同时包含当前为空的文件夹，以及删除所选文件后将变空的文件夹：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --ext ".c,.h" --empty-dirs
```

空文件夹预览默认显示 20 个，可独立调整：

```powershell
.\filetype-cleaner.exe --root "D:\rom_workspace" --empty-dirs --empty-dir-preview 50
```

执行时先处理文件，再从最深层向上重新检查并删除空文件夹。根目录永不删除；排除目录、非空目录、符号链接以及扫描后变为非空的目录都会保留。

## 展平模式

使用 `--flatten` 预览把所有子目录普通文件移动到根目录的计划。新文件名会加入原相对路径，各级路径使用 `__` 连接：

```text
D:\data\a\b\file.txt  ->  D:\data\a__b__file.txt
```

```powershell
.\filetype-cleaner.exe --root "D:\data" --flatten
```

确认预览后使用 `--apply` 执行；交互确认需要输入大写的 `MOVE`：

```powershell
.\filetype-cleaner.exe --root "D:\data" --flatten --apply
```

自动化执行可增加 `--yes`，也可以在移动成功后删除已经为空的原目录：

```powershell
.\filetype-cleaner.exe --root "D:\data" --flatten --apply --yes --empty-dirs --log "flatten.log"
```

展平默认选择全部子目录普通文件。也可以用 `--ext`、`--no-ext` 限定类型，或配合 `--invert` 只保留指定类型；`--exclude` 和 `--exclude-content` 同样有效：

```powershell
.\filetype-cleaner.exe --root "D:\data" --flatten --ext ".jpg,.png"
.\filetype-cleaner.exe --root "D:\data" --flatten --ext ".c,.h" --invert
```

根目录已有文件不会改名。符号链接和链接型重解析点也不会移动，避免改变相对链接的含义。生成名重复时会自动在扩展名前增加序号，并继续避开根目录已有名称：

```text
a__b__file.txt
a__b__file (2).txt
a__b__file (3).txt
```

程序始终不会覆盖已有文件。编号后超过 Windows 单个文件名 255 个 UTF-16 单元限制的文件会保留，并在预览中标明原因。

## 安全行为

- 默认只扫描和预览，不删除文件。
- 展平模式默认也只预览，只有 `--flatten --apply` 才会移动文件。
- 展平移动绝不覆盖根目录已有目标；重复名称默认自动增加 `(2)`、`(3)` 等序号。
- 展平时根目录文件、链接和生成名过长的源文件都会保留。
- 排除关键词优先于扩展名和无扩展名匹配。
- 内容关键词匹配不区分大小写；删除前会再次检查，检查失败或超过上限时保留文件。
- 反向模式执行删除前会再次检查文件扩展名，已变为保留类型的文件会被跳过。
- 空文件夹执行删除前会重新检查，只有仍为普通空目录时才删除，且永不删除扫描根目录。
- 0 字节文件正常计数、预览和处理。
- 匹配的符号链接和链接型重解析点会计数和处理；删除时只移除链接本身，不跟随或删除链接目标。
- 真正删除前重新检查文件类型和扩展名。
- 默认在扫描出现权限或读取错误时取消实际处理。
- 拒绝直接在 `C:\`、`D:\` 等磁盘根目录执行删除或展平。
- 删除是永久操作，不进入回收站。

扫描时显示已扫描和已匹配数量；删除或展平时显示以文件数量计算的进度条、百分比、成功数和失败数。进度不依赖文件大小，因此 0 字节文件也会正常推进。

## 参数

```text
--root PATH             要扫描的根目录（必填）
--ext LIST              逗号分隔的扩展名
--no-ext                同时匹配无扩展名文件，可独立使用
--exclude LIST          排除相对路径中含有的关键词，逗号分隔且忽略大小写
--exclude-content LIST  保留内容中含有关键词的普通文件，逗号分隔且忽略大小写
--content-max-mib N     内容检查的单文件上限，默认 16 MiB；0 表示不限制
--invert                反向模式：保留指定类型，处理其他类型
--delete                实际删除；不指定时仅预览
--flatten               展平模式：把子目录文件移动到根目录并在文件名中加入原路径
--apply                 实际执行展平移动，必须与 --flatten 同时使用
--yes                   跳过 DELETE/MOVE 确认
--workers N             删除或移动并发数，范围 1-64，默认最多 4
--preview N             显示前 N 个匹配路径，默认 20
--keep-preview N        显示前 N 个明确保留的路径及原因，默认 20
--empty-dirs            同时处理当前为空或处理后变空的文件夹，可独立使用
--empty-dir-preview N   显示前 N 个空文件夹候选，默认 20
--log PATH              追加写入处理结果和错误日志
--ignore-scan-errors    扫描不完整时仍处理已经找到的文件
--version               显示版本
```

SSD 可以从默认的 4 个 worker 开始测试。机械硬盘通常建议使用 `--workers 1` 或 `--workers 2`，过高的并发可能因随机访问而更慢。

```powershell
go test ./...

```
